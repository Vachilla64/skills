Add the Speak skill suite (`speak`, `setup-speak`, `edit-speak`) under `skills/productivity/`.

- `speak`: Model-invoked skill giving agents an ambient voice via local neural TTS (Pocket-TTS, Kokoro, Kitten TTS) using a fire-and-forget background execution pattern.
- `setup-speak`: User-invoked wizard that detects the host platform, helps choose an engine, auditions candidate voices aloud through the speakers, and configures tone, frequency, and task triggers.
- `edit-speak`: User-invoked skill to quickly adjust speech preferences in place without re-running engine installation.
